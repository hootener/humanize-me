# Invariants the template ships with its tooling

Generated by `bin/index` from this brain's own decisions, for the ones
that declare they govern generic paths. `bin/constraints` reads this after
your own catalog, so a decision about `bin/**` reaches you along with the
`bin/**` it governs. Your own node of the same id always wins.

Do not edit: it is regenerated upstream and replaced by `bin/update`.

## D0002 Every node belongs to one of four categories, and nothing cites a node newer than itself
- invariant: No node may cite a node that is newer than itself.
- constrains: bin/lint, bin/ancestry, bin/graph-build
- url: https://github.com/hootener/brain/blob/main/knowledge-catalog/decisions/D0002-four-categories.md

## D0003 Identifiers are a type letter and a flat global four-digit sequence
- invariant: An id is unique across the brain and is never reused or renumbered except to resolve a collision.
- constrains: bin/lint, bin/new, bin/renumber, bin/ancestry
- url: https://github.com/hootener/brain/blob/main/knowledge-catalog/decisions/D0003-identifiers.md

## D0005 Approach nodes name the goal they serve, and decisions carry a machine-readable claim
- invariant: Every Approach node names at least one goal, so every lineage branch terminates in Intent.
- constrains: bin/ancestry, bin/constraints, bin/lint, skills/to-spec, skills/grill-change
- url: https://github.com/hootener/brain/blob/main/knowledge-catalog/decisions/D0005-intent-layer-wiring.md

## D0007 Every status transition has one named owner, and the brain is kept current in three layers
- invariant: A status transition with no named owner does not happen, and no tool changes an inferred status without an answer.
- constrains: bin/reconcile, bin/status, bin/lint, skills/implement, skills/spec-review, skills/audit
- url: https://github.com/hootener/brain/blob/main/knowledge-catalog/decisions/D0007-status-ownership.md

## D0008 A blocker is a node, not a sentence
- invariant: A task's blocker is a link to a node, never free text.
- constrains: bin/status, bin/lint, skills/triage, skills/implement
- url: https://github.com/hootener/brain/blob/main/knowledge-catalog/decisions/D0008-a-blocker-is-a-node.md

## D0009 An open question that blocks work is a task; one that blocks nothing is a note
