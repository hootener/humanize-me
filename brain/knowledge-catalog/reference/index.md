# Reference

**Evidence**: how things actually are, as opposed to how they were decided to
be. Stack facts, measurements, gotchas, research notes, and what a review or
an audit found.

An evidence node that corrects something upstream carries `amends:`; one that
records a looking-back pass carries `reviewed:`; one that was given rather
than gathered carries `resource:`. A plain measurement carries none.
