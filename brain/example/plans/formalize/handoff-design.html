Handoff · design

Ready the brain for other people to adopt

Close the gaps the first two real adoptions exposed, so a second operator can install this brain into a project already in flight and trust what it tells them.

In short

This repository is a system for keeping the reasoning behind a project — the goals, the decisions, the plans, what was learned afterwards — as plain files that a person, a diff and an agent can all read. It works for the person who built it. This work is about making it work for somebody else.

Two real projects have now adopted it. Between them they surfaced a dozen defects, none of which the system's own checks could have found, because a system that checks itself passes by construction. What is left is the difference between a tool that works in the hands that made it and one that survives being handed over.

When this is done, someone who has never seen the repository can fork it, install it into a project they are already halfway through, and have the record stay true as they work — without being taught the system first.

This serves A brain someone else can adopt without being told how.

The decisions that bind this

D0002
Every node belongs to one of four categories, and nothing cites a node newer than itself

No node may cite a node that is newer than itself.

D0005
Approach nodes name the goal they serve, and decisions carry a machine-readable claim

Every Approach node names at least one goal, so every lineage branch terminates in Intent.

Not included

  • A hosted service, a database, or any runtime. The files are the product.
  • Deadlines, consent dates, release processes, and anything else that models a
  • particular team's way of working rather than the work.
