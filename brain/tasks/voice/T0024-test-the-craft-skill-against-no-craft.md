# What to build

A two-arm trial of `_craft/writing-for-humans.md` — the 1,818 words every voice
skill loads, and the only shipped component with no controlled trial behind it.
Every trial so far tested a personal voice profile, which does not ship.

Under [D0031](../../knowledge-catalog/decisions/D0031-the-shipping-metric-is-reader-burden-measured-as.md)
the endpoint is reader burden, not resemblance.

# Design

- **Arms.** Same content-only brief to two fresh generating agents; one loads
  the craft skill, one gets no writing guidance. No voice profile in either
  arm — this is a test of the craft, not of fidelity.
- **Briefs.** Content-only, written by a separate agent, mechanically checked
  for leaked headings and shared shingles before use, per the method in
  `voice-harvest`.
- **Primary endpoint.** Named defects per 100 words, blind, one passage at a
  time, with the question *what is wrong with this one?* —
  [D0022](../../knowledge-catalog/decisions/D0022-the-preference-signal-is-named-defects-never-blind.md)
  forbids asking which is better.
- **Guard-rail.** Report Flesch and Flesch-Kincaid for both arms. They are
  there to show the craft arm did not win by chopping sentences, and are not
  evidence of improvement
  ([E0015](../../knowledge-catalog/reference/E0015-classical-readability-formulas-rank-agent-prose-above-the.md)).
- **Pre-registration.** Rubric, prediction and scoring script written to disk
  before either arm runs, as in
  [E0014](../../knowledge-catalog/reference/E0014-voice-draft-changed-every-drafting-behaviour-it-claims.md).
  Record in advance what a null result would mean.

# Acceptance criteria

- [ ] Briefs verified free of leaked structure before generation
- [ ] Both arms generated by fresh agents that have not read this record
- [ ] Prediction and rubric on disk, timestamped before generation
- [ ] Defects named blind, one passage at a time
- [ ] Result recorded as evidence whichever way it goes, including a null
- [ ] Readability formulas reported as a guard-rail and not as a result

# Open question that gates this

**Who judges.** Both of D0031's primary measures need a reader who is not the
operator, and he is the only judge this project has ever had. Using him again
keeps n at one and measures his preferences; recruiting anyone else changes the
claim from *cheaper for him* to *cheaper for a reader*, which is the claim the
README actually makes.

This is not a detail to settle during the run. It decides what the result means.
