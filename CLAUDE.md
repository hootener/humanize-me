# humanize-me

A library of voice skills to drop into other projects, so a coding agent writing
prose **for a human reader** stops sounding like a coding agent.

Scope note: this is about human-to-human prose only. Text written to be consumed
by another agent is out of scope and does not need to sound like anyone.

Project knowledge lives in `brain/` — see [brain/CLAUDE.md](brain/CLAUDE.md).
